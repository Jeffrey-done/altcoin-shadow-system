**状态**: 待审批 (实现前请先 review)  
**前置原则**: 不为发新策略而发新策略；每个新策略都要解决现有 3 策略覆盖不到的真实场景

---

## 一、现有策略覆盖分析

| 策略 | 触发场景 | 弱点 |
|------|---------|------|
| short_overbought | 日线 RSI≥75 + 4h 回落/弃盘 | 错过"已经回调一波再继续跌"的二次机会；对趋势性下跌捕捉力弱 |
| long_oversold | 日线 RSI≤25 + 4h 反弹 | 抓不到"非超卖区的强势回调买点"；震荡市表现一般 |
| prepump_sniffer | OI 异动+资金费率回归+量能预热 | 信号稀疏，且偏赌博性质；与其他策略相关性低（这是优点） |

**覆盖盲区**：

1. **极端事件后的均值回归**（清算潮后的反弹、闪崩后的修复）—— 加密市场最稳定的 alpha 来源之一
2. **结构性资金面失衡**（资金费率持续单边极端）—— 永续合约独有的可交易因子
3. **波动率压缩后的方向性突破**（横盘整理后的 trend init）—— 经典低频高胜率
4. **横截面强弱**（同板块内的相对强势）—— 与单 symbol 策略不同的维度

## 二、为什么大多数"加密策略"都不赚钱（先讲反面）

我先把会被坑的常见错觉列出来，避免后续设计时踩坑：

### ❌ 不要做这些

1. **裸 RSI 背离做反转** —— 强趋势中背离会持续数周，纯背离信号胜率不到 45%
2. **均线金叉死叉** —— 滞后严重，加密市场已被算法套利吃干净，胜率 ~50%
3. **新闻事件交易** —— 信息不对称，散户永远是接盘侠
4. **追"涨幅榜冠军"** —— 已知的 MAX 效应反向，长期负收益
5. **简单的支撑阻力** —— 可视化偏差，事后看准事前难判断
6. **抄学术论文里的因子** —— 90% 的论文 alpha 已被市场吸收掉，且学术 backtest 通常忽略真实滑点和资金费率成本

### ✅ 真正在加密永续上能赚钱的几类信号（基于实证）

| 类别 | 为什么能赚钱（结构性原因） | 难度 |
|------|---------------------------|------|
| **清算反弹** | 强平算法集中触发，造成短期价格 overshoot；冷静后修复是机制必然 | 中 |
| **资金费率极端反转** | 一边付费给另一边，长期付费成本累积 + 拥挤交易必然均值回归 | 中 |
| **波动率扩张** | 波动率有强自相关性，压缩后 90%+ 概率扩张；只是方向不一定 | 中 |
| **跨所价差** | 套利者数量有限，临时价差可被捕捉 | 高（速度战） |
| **板块轮动** | 资金在赛道间流动有惯性；强势板块强势币持续 1~3 周 | 中 |

**我提议的 3 个策略都在这 5 类里挑了"中等难度但结构稳定"的——不追求 cutting-edge，追求胜率高+逻辑可解释。**

## 三、提议的 3 个策略

### 策略 A: `liquidation_reversal_long` （清算反弹做多）

#### 1. 边际优势 (Edge Thesis)

**结构性逻辑**：永续合约采用强平算法，当价格快速下跌时，触发的强平单不是按"心理价位"成交，而是市价砸盘，造成短期 overshoot。强平结束后，做空者已平仓获利，没有持续抛压，价格自然修复 3~8%。

**证据来源（业内实证，非学术论文）**：
- Binance 大额强平（>$10M/分钟）后 4 小时内反弹概率，业内交易员普遍反馈在 60~70%
- 历史案例：2024 年 8 月 5 日"日元套息平仓"导致 BTC 跌至 $49K，4h 后反弹 8%；类似事件在山寨币上更频繁
- 山寨币波动率 2-3x BTC，强平 overshoot 更明显

#### 2. 入场条件（必须**全部**满足，多重过滤防止追跌停板）

| Gate | 条件 | 目的 |
|------|------|------|
| G1 | 1h 跌幅 ≥ 4% **或** 4h 跌幅 ≥ 8% | 必须有"急跌"，慢跌不算清算 |
| G2 | 1h 成交量 ≥ 24h 均量的 2.5x | 量价配合，确认是恐慌抛盘 |
| G3 | 当前价距 4h 最低点 ≤ 2% | 必须接近底部，不接半山腰刀 |
| G4 | RSI(1h) ≤ 25 **且** RSI(4h) ≤ 35 | 双周期超卖确认 |
| G5 | 资金费率 ≤ -0.02%/8h | 空头开始过度拥挤（重要！） |
| G6 | BTC 1h 跌幅 ≤ 6% | 大盘崩盘时不接刀（系统性风险隔离） |
| G7 | 该币近 30 天没出现过此入场（去重） | 避免对单一品种过拟合 |

**为什么这 7 个 Gate 缺一不可**：
- 缺 G1/G2：可能在缓慢下跌中买入，没有反弹动能
- 缺 G3：可能在反弹中段追入，止损风险大
- 缺 G4：RSI 不极端，反转概率不足 50%
- 缺 G5：空头还没拥挤，可能继续跌
- 缺 G6：系统性风险下个股反弹也无效

#### 3. 评分系统（满分 100）

每个因子的权重**不是拍脑袋**，而是按预测胜率边际贡献排序：

| 因子 | 满分 | 权重逻辑 |
|------|------|---------|
| **跌幅严重度** | 0~25 | 跌得越深反弹空间越大；4h-15% 给满分 |
| **成交量倍数** | 0~20 | 量越大确认越强；6x 24h均量给满分 |
| **资金费率深度** | 0~20 | 空头越拥挤反弹越猛；-0.1% 给满分 |
| **RSI 超卖深度** | 0~15 | RSI(1h)15 给满分，RSI(1h)25 给 8 分 |
| **距低点接近度** | 0~10 | 距 4h 低点 0.5% 内给满分，2% 给 5 分 |
| **BTC 配合度** | -10 ~ +10 | BTC 涨给加分；BTC 同步跌减分 |

**阈值**：
- ≥75 分 = A 级，开 1.0× DEFAULT_STAKE 全仓
- 60~74 分 = B 级，开 0.6× DEFAULT_STAKE 半仓
- <60 分 = 不开仓（**比现有 40 分阈值严格得多**，因为反转策略容错低）

#### 4. 止盈止损（不对称 R:R 是关键）

```
入场 → 硬止损 -3.5% (急跌后再跌 3.5% 说明判断错)
     → TP1 +4%, 半仓出（捕捉机制反弹）
     → TP2 +8%, 剩余出
     → 移动止损：盈利 ≥3% 后激活，回撤 35% 触发
     → 时间止损：8 小时未盈利 ≥2% 强制平
```

**R:R 设计**：
- 全仓 R:R = 8% : 3.5% = **2.29**（盈亏比 2.29:1）
- 半仓 R:R = 4% : 3.5% = **1.14**（保本以上盈利）

#### 5. 胜率与期望

**目标胜率**: 60~68%

推算（用未来 4 周 backtest 验证后调整）：
- 假设胜率 62%，平均赢 5.5%（混合 TP1/TP2/移动止损），平均输 3.2%（混合硬止损/时间止损）
- 期望 = 0.62 × 5.5 + 0.38 × (-3.2) = 3.41 - 1.22 = **+2.19% / 笔**
- 假设每周 3~5 笔触发，月期望 ROI ≈ 25~45%（10x 杠杆下）

**关键风险**：
- 极端黑天鹅（监管/交易所暴雷）会击穿止损
- 长期下跌趋势中信号会反复触发（连亏）→ 用风控的连亏暂停兜底

### 策略 B: `funding_extreme_reversal` （资金费率极端反向 · 双向）

#### 1. 边际优势

**结构性逻辑**：永续合约的资金费率是多空双方互相支付的成本。当费率持续单边极端（>+0.1%/8h 或 <-0.05%/8h），意味着持仓严重一边倒。这种拥挤交易在加密市场会被对手方"挤爆"。

**证据**：
- 学术参考：He et al. 2022 *Fundamentals of Perpetual Futures*（论证永续与现货价差与费率正相关）— 内容已重述以符合许可
- 实证：Binance 上 BTC 费率 >0.1%/8h 时，未来 24h 平均回撤 1.5~2%；山寨币因杠杆更高，效应放大 2~3x
- 直觉：长头每 8h 付 0.1%（年化 109%！），不可能持续，必然平仓引发回撤

#### 2. 入场条件

**SHORT 方向**（多头过度拥挤）：

| Gate | 条件 |
|------|------|
| G1 | 资金费率 ≥ +0.08%/8h（年化 ≥87%）持续 ≥2 个 8h 周期 |
| G2 | 7 天累计涨幅 ≥ 25% |
| G3 | RSI(4h) ≥ 60（已偏高位）|
| G4 | OI 7天增长 ≥ 30%（多头确实在加仓，不是被动拥挤）|
| G5 | 4h K 线连续 2 根上影线 > 实体 1.5x（顶部承压信号）|
| G6 | BTC 不在强势上涨阶段（24h ≤ +5%）|

**LONG 方向**（空头过度拥挤）：

| Gate | 条件 |
|------|------|
| G1 | 资金费率 ≤ -0.05%/8h（年化≤-54%）持续 ≥2 个 8h 周期 |
| G2 | 7 天累计跌幅 ≥ 15% |
| G3 | RSI(4h) ≤ 40 |
| G4 | OI 7天增长 ≥ 20%（空头在加仓）|
| G5 | 4h 出现长下影线 K（>实体 1.5x）|
| G6 | BTC 不在崩盘阶段（24h ≥ -5%）|

#### 3. 评分系统（满分 100）

| 因子 | 满分 | 说明 |
|------|------|------|
| **费率绝对值** | 0~30 | 越极端权重越高（最核心因子）|
| **费率持续时间** | 0~15 | 持续 2 个周期=8 分，3+ 周期=15 分 |
| **价格 overextension** | 0~15 | 7d 涨/跌 25%=8 分，40%+=15 分 |
| **RSI 配合** | 0~15 | RSI 越极端配合度越高 |
| **OI 方向确认** | 0~10 | 必须 OI 同向增长才算"主动拥挤" |
| **K 线反转形态** | 0~10 | 长影线/十字星 = 满分 |
| **跨所一致性** | 0~5 | Binance + OKX 费率同向极端 = 满分 |

阈值：≥70 全仓，55~69 半仓，<55 跳过。

#### 4. 止盈止损

```
SHORT:
  硬止损 +4% (做空容错略大，因为持仓时间长)
  TP1 +5%, 半仓
  TP2 +9%
  移动止损：盈利≥4% 后回撤 35% 触发
  时间止损：48h（让费率成本累积发挥作用）

LONG (镜像):
  硬止损 -4%
  TP1 +5%, 半仓
  TP2 +9%
  移动止损同上
  时间止损 48h
```

**特殊优势**：持仓期间持续收取/避免支付资金费率，单是这个就有 0.3~0.6%/天的隐性收益。

#### 5. 胜率与期望

**目标胜率**: 55~62%

期望值推算：
- 胜率 58%，平均赢 6%，平均输 3.8%（含资金费率收益）
- 期望 = 0.58 × 6 - 0.42 × 3.8 = 3.48 - 1.60 = **+1.88% / 笔**

### 策略 C: `squeeze_breakout` （波动率压缩突破 · 双向）

#### 1. 边际优势

**结构性逻辑**：波动率有强自相关性（"波动率聚集"是金融学最稳定的事实之一）。当波动率压缩到极低分位（BB 带宽<历史 20%），后续 1~3 天内扩张概率 >85%。突破方向往往延续，因为：(a) 压缩区间累积大量止损订单，(b) 算法策略集中追单。

**证据**：
- 实证：BB 带宽 20% 分位以下，未来 5 日真实波动率均值是 30 日均值的 1.5~2.0x
- 关键：**这不是预测方向，而是预测波动率扩张**。我们在突破方向出现时跟随，让 R:R 来兜底胜率不足

#### 2. 入场条件

**SQUEEZE 识别（共同前提）**：

| Gate | 条件 |
|------|------|
| G1 | 4h BB(20, 2) 带宽 ≤ 过去 30 天分位 20% |
| G2 | 压缩持续 ≥ 12 根 4h K 线（48 小时）|
| G3 | 4h ATR(14) ≤ 30 天 ATR 均值的 70% |

**LONG 突破方向**：

| Gate | 条件 |
|------|------|
| G4 | 当前 4h 收盘 > BB 上轨 |
| G5 | 当前 4h 成交量 ≥ 30 根 4h 均量的 2x |
| G6 | 当前 K 线实体 ≥ 5 倍 ATR(14)（必须是真突破，不是虚晃）|
| G7 | RSI(4h) > 55（动量同向）|

**SHORT 突破方向**（镜像）：
- 收盘 < BB 下轨 + 量倍 + 大实体 + RSI(4h) < 45

#### 3. 评分系统（满分 100）

| 因子 | 满分 | 说明 |
|------|------|------|
| **压缩深度** | 0~20 | BB 带宽分位越低权重越高 |
| **压缩时长** | 0~15 | 48h=8 分，96h+=15 分 |
| **突破成交量** | 0~25 | 量越大越可信（核心因子，避免假突破）|
| **K 线实体强度** | 0~15 | 大阳/大阴线给满分，吊颈线/十字星扣分 |
| **多时间框架共振** | 0~15 | 1h+4h+1d 三周期方向一致 = 满分 |
| **支撑/阻力突破** | 0~10 | 同时突破前期高点/低点 = 满分 |

阈值：≥75 全仓，60~74 半仓，<60 跳过。

#### 4. 止盈止损（**关键：不对称大 R:R**，因为胜率本身只有 50%）

```
入场价 (突破点) → 
  硬止损：BB 中轨（约 -2.5% ~ -4%）
  TP1: +5%（半仓）
  TP2: +12%
  移动止损：盈利≥5% 后回撤 30%
  时间止损：72h（趋势没起来就退出）
```

R:R 设计：
- 全仓 = 12% : 3.5% = **3.43**
- 半仓 = 5% : 3.5% = **1.43**

#### 5. 胜率与期望

**目标胜率**: 50~58%（突破策略本身胜率就低，靠 R:R 弥补）

期望值：
- 胜率 53%，平均赢 8.5%（混合 TP1/TP2/移动），平均输 3.2%
- 期望 = 0.53 × 8.5 - 0.47 × 3.2 = 4.51 - 1.50 = **+3.01% / 笔**

胜率虽低，但因 R:R 大，期望反而比 A/B 高。但波动也大，建议比例小一些。

## 五、币种价格范围调整建议

**现状**：
- `PRICE_MAX = 50` USD
- `VOL_MIN = 500,000` USDT/24h
- `BATCH_BACKTEST_SYMBOLS` 含 PEPE / DOGE / FET / SUI / APT 等 20 个

**问题诊断**：
1. `VOL_MIN = 50万` 偏低，山寨币现在普遍流动性更深；500万 U 都算流动性一般了
2. `PRICE_MAX = 50` OK，但没考虑"市值"维度——某些 0.5U 的币可能是死币
3. 策略 A/B 需要 OI/funding 数据完整性，建议**仅在有永续合约的币上跑**

**建议调整**：

| 参数 | 现值 | 建议 | 理由 |
|------|------|------|------|
| `VOL_MIN` | 500,000 | **3,000,000** | 流动性下限上调，避免被滑点吃光 |
| `PRICE_MAX` | 50 | **保持 50** | 已经合理，覆盖中盘 |
| `MIN_OI_USDT`（新增）| - | **5,000,000** | OI 太小的币费率信号失真 |
| `BATCH_BACKTEST_SYMBOLS` | 20 个 | **扩到 30 个** | 加入 LINK/AVAX/DOT/MATIC/UNI/ATOM/LTC/XRP/ADA/TRX 等老牌中盘 |

新策略的 `vol_min` 各自单独配置：
- 策略 A：5,000,000（清算需要厚流动性，否则止损会被穿）
- 策略 B：3,000,000（费率信号在中等流动性也有效）
- 策略 C：3,000,000（突破策略容许稍小盘）

## 六、实现优先级 & 风控

### 实施顺序（建议）

1. **第一周**：先实现 **策略 A (liquidation_reversal_long)** —— 胜率最高、逻辑最稳定，先跑 testnet 14 天验证
2. **第二周**：策略 A 数据 OK 后，加 **策略 C (squeeze_breakout)** —— 与 A 相关性低，不会同时爆
3. **第三周**：再加 **策略 B (funding_extreme_reversal)** —— 需要费率历史数据准确，调试期长一点

### 三道兜底（防止设计失误带来的真亏）

1. **影子模式优先**：3 个策略都先 `enabled: true` 但 `live_mode: false`，**只跑影子 14 天**，看实际胜率
2. **降仓位灰度**：实盘前 7 天 `default_stake` 砍半（15U 而非 30U）
3. **熔断阈值**：每个策略**单独**的 `RISK_MAX_DAILY_LOSS = 15U`，触发即关该策略 24h（避开模型失效区）
